# Video to GIF Converter (MoviePy 2.x)

Convert an `.mp4` (or other video formats) into an animated `.gif` with optional trimming, speed-up/slow-down, resizing, and FPS control.

---

## Features
- ✅ Convert video to GIF
- ✅ Trim by `start_time` and `end_time`
- ✅ Change playback speed with `speed_factor`
- ✅ Resize by width while preserving aspect ratio
- ✅ Control GIF smoothness using `fps`
- ✅ Basic validation and error handling

---

### Python
- Python **3.8+** (recommended: 3.10+)
